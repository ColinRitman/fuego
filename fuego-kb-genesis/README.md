## 🎯 KB Conventions

### 📝 **File Naming**
- `00-` prefix = Index/Overview
- `01-09` prefix = Ordered sections
- Lowercase with hyphens for URLs
- `.md` format (Markdown)

### 🏷️ **Tagging System**
- `V10+`: V10 and later
- `V8+`: V8 and later
- `V2-V7`: Specific to these versions
- `HARD`: Hard fork required
- `SOFT`: Soft fork compatible
- `NO-FORK`: Client-only

### 🔗 **Linking Format**
- `[KB-02.03]` = 02-IMPLEMENTATION-GUIDELINES/03-change-mgmt.md
- `[V10-EX]` = V10 code example
- `[SEC-01]` = 06-SECURITY-PRACTICES/01-crypto-review.md
