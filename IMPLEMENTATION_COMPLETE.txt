   Purpose: Bare-bones RPC check for commitment existence on Fuego blockchain
   Method: POST /json_rpc with method "check_commitment_exists"
   Response: { exists: bool, block_height: uint64, status: "OK" }

✅ Task 4: Refactored API /api/claim for Domain Signatures
   File: xfg-stark/api/src/routes/claim.ts
   Changed: Old flow (API calls contracts) → New flow (stateless verification)
   
   New Flow:
   1. User submits EIP-712 signed claim key + signature
   2. API validates signature
   3. API queries Fuego RPC: "Does commitment exist?"
   4. API generates Ed25519 domain signature
   5. API returns signature (NO LOGGING, NO PERSISTENCE)
   
   Properties:
   - Stateless (no database writes)
   - Zero data logging (no privacy leaks)
   - Scalable (horizontal scaling)
   - User-controlled (claim key never sent to API)

✅ Task 5: Added Domain Signature Verification to L2 Contract

   - Renamed claimCDInterest() to claimCD()

   - Added isClaimKeyUsed() public query function
   
   Security:
